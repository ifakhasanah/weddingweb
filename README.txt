OURWEDS — STATIC WEDDING INVITATION WEBSITE

Files:
- index.html: website structure and page content
- style.css: layout, responsive styles, typography
- script.js: cover interaction, countdown, RSVP demo, optional music button
- images/: local SVG illustrations used by the page

HOW TO OPEN
1. Extract the ZIP file.
2. Open index.html in a modern browser.
3. For best results, keep index.html, style.css, script.js, and the images folder together.

CUSTOMIZE BEFORE PUBLISHING
- Replace Alya & Raka and the family names in index.html.
- Update the date/time in index.html and the weddingDate value in script.js.
- Replace the sample venue/address and Google Maps links.
- Replace gradient gallery tiles with your own photos if desired.
- The RSVP form is a front-end demo; it does not send responses to an email or database. Connect it to a form service or backend before using it for real guests.
- Optional fonts load from Google Fonts; fallback fonts are included if unavailable.
- To personalize a guest link, use index.html?to=Nama%20Tamu.
